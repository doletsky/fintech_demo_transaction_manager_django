# Как работает проект

## Общая идея

Это система управления финансовыми транзакциями — депозитами, снятиями и платежами. Каждая транзакция проходит через жизненный цикл (создана → на обработке → подтверждена/отклонена), и всё записывается в аудит-лог.

## Как устроено

### 1. REST API (Django + DRF)
Приложение предоставляет API для работы с транзакциями. Django REST Framework (DRF) автоматически обрабатывает сериализацию данных, валидацию и формирование ответов.

### 2. Идемпотентность
Если один и тот же запрос отправить дважды (например, из-за проблем с сетью), система не создаст дубликат. Для этого используется `Idempotency-Key` — уникальный ключ в заголовке запроса. Если ключ уже был использован, возвращается результат предыдущего запроса.

### 3. Аудит-лог
Каждое изменение транзакции записывается в отдельную таблицу аудита: кто, когда и что сделал. Это позволяет отследить всю историю изменений.

### 4. Фоновые задачи (Celery)
Некоторые операции выполняются в фоне, чтобы не заставлять пользователя ждать:
- **Подтверждение транзакции** — через несколько секунд после создания, транзакция автоматически подтверждается
- **Уведомления** — отправка уведомлений о статусе транзакции

Celery использует Redis как брокер сообщений — он передаёт задачи от API к воркеру.

### 5. Мок PayPal
Имитация PayPal для оплаты:
- **create** — создаёт платёж, привязанный к транзакции
- **capture** — подтверждает списание средств
- **webhook** — PayPal «уведомляет» систему об успешной оплате, статус транзакции меняется на "completed"

### 6. Логирование и мониторинг
Все действия логируются в формате JSON: создание транзакции, изменение статуса, ошибки. Логи собираются Promtail и отправляются в Loki. В Grafana можно искать логи по transaction_id, user_id, payment_status.

### 7. Docker
Все компоненты работают в контейнерах:
- **web** — Django-приложение
- **db** — MySQL
- **celery_worker** — обработчик фоновых задач
- **redis** — брокер для Celery
- **loki + promtail + grafana** — стек логирования

## Поток данных

```
Пользователь → API (DRF) → Транзакция в MySQL
                   ↓                    ↓
              Аудит-лог          Celery задача → Redis → Worker → подтверждение
                   ↓
              Мок PayPal (create → capture → webhook)
                   ↓
              JSON-логи → Promtail → Loki → Grafana
```
